## 学习方法论

以论文/项目为主线拉动学习，遇到不懂的基础知识记到 `99_按需补课/`，不单独系统通读教材。每篇论文分三遍消化：

1. **第一遍**（碎片30min）：摘要 + 引言 + 图表 → 搞清解决什么问题
2. **第二遍**（集中2h）：方法章节 + 数学推导 → 搞清怎么做的
3. **第三遍**（集中3-4h）：跑代码 / 复现 → 搞清实际怎么用
